# 📦 HSL YouTube Packaging & SEO Distribution Skill

Esta skill orquestra a engenharia de conversão e CTR para o canal **Hidden Systems Lab (HSL)**, combinando neurociência visual de retenção imediata (<200ms) com a fórmula de títulos `1 + 1 = 3`.

---

## 🎨 FÓRMULA DAS 3 THUMBNAILS 4K (TESTE MULTIVARIÁVEL A/B/C)

```text
[ MATRIZ DE THUMBNAILS HSL (3840x2160 / 1920x1080) ]
├── Variante A (FACE + EVIDENCE): Rosto humano de espanto/foco (40% do quadro) guiando o olhar para a evidência técnica em Laranja Hiper (#FF2E00).
├── Variante B (BEFORE vs AFTER): Split screen diagonal com linha divisória luminosa contrastando operação normal vs colapso total do sistema.
└── Variante C (HERO OBJECT): Macro industrial monumental em fundo Obsidian escuro com retícula de telemetria circular travada no gargalo.
```

---

## 🧠 PSICOLOGIA DE TÍTULOS (REGRA 1 + 1 = 3)

- **Princípio:** A Thumbnail cria a **tensão/pergunta visual incompleta**. O Título fornece o **contexto operacional que justifica o clique**.
- **Proibição Rígida:** NUNCA repetir o texto da thumbnail dentro do título.
- **Estrutura dos 3 Títulos Estratégicos:**
  1. *Título de Busca / Intenção Direta:* `How [System] Moves [Throughput] Without [Failure]`
  2. *Título de Curiosidade / Mecanismo:* `The [Hidden Vulnerability] That Almost Stopped [Entity]`
  3. *Título de Paradoxo / Contradição:* `The Invisible Pipe That Keeps Every Passenger Flight in the Air`

---

## ⚡ PROCEDIMENTO DE EXECUÇÃO & COMANDOS

```bash
# 1. Gerar o pacote de publicação completo (3 Thumbnails + Títulos + SEO):
npm run hsl:package

# 2. Validar conformidade de empacotamento:
npm run hsl:verify -- --with-packaging

# 3. Auditoria de conformidade total do PRD:
npm run hsl:compliance
```
